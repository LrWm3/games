Grow a factory, across scales

Turn raw deposits into Quantum Cores. Stored materials in Central Command and depots pay for construction.

  1. Build a Micro Miner on the nearby Iron Ore circle.
  2. Build a Micro Assembler on empty ground. Select it and choose Smelt Iron.
  3. Select the miner, choose Route output, then select the assembler. Route the assembler back to Central Command.
  4. Repeat for copper. Feed plates and wire into another assembler to make circuits.
  5. Zoom out for Titanium and Uranium deposits. Build Macro and Mega machines using materials from the previous tier.

Map: drag to pan, scroll or pinch to zoom. + / − also zoom. Home returns to Central Command. Escape cancels placement or routing.

Recovery: remove routes in a building’s details. Dismantling returns all materials; changing recipes returns unused inputs to Central Command.

Demo · no autosave. Reloading starts a new world. Deposits are infinite; routes transfer one item per tick.
